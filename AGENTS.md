# sysd

This project is about creating a design system that I can use in my other projects whenever I have a need for a consistent
and profesional tone that is my own.

First goal is to have something I can use on the web.

I also want to do this because I feel that increesingly this is the direction that the industry is moving. 
More and more companies want to have their own design system to have consistentcy across multiple platforms. 
And with the help of AI this is now a posibility, when before it was simply to much work.

It also connects to my bigger ambition of building an online design system generator/builder/tool where designers can create a design system through a web interface.

So let's build this the way you would build it for a client.

Its called 'sysd'

## Design brief

### Key words and character

Elegant, precise, cool, calm, poetic, typographic design excellence,
Typographic hierarchy, simplicity, columns of small text , modern school bauhaus, grid layouts, free flowing columns.
Modern design mannerisms, light greys contrasted with bold splashes of color, love of type, boring but not boring , playfull
but academic, craftmanship, swiss design, Josef Müller-Brockman.

### Should work on 

- Touch screens and keyboard and mouse or trackpad. Be accessible.
- Small and large screens
- Accross all web frontend frameworks

Should have themes, at least a light and a dark mode

### Where it will be used

First place is 
- my own personal homepage
- a personal blog or 
- collection of article pages.

The idea is to create a tool that will make it easy to make beautiful articles pages but still have a playfull approach that will allow creativity.
Im a grafic designer. I like flat colored limited pallete well composed simple designs. Delibarate white space. I like all the great modern graphic designers. The most important colors are light and dark. Did I say white space.

### Technology

Pure CSS / Modern CSS Modules with CSS Variables
So much has happend in the CSS space lately. I want to use the modern CSS way of doing things.

### What is a design system

A design system is a maintained set of reusable decisions (design tokens, components, and patterns) together with explicit, machine-readable rules for applying them. It gives authors, human or AI, a shared vocabulary for building interfaces that are consistent in appearance and behavior, while staying expressive enough that they rarely need to step outside it, and constrained enough that it can verify when they do.
